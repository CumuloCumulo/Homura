# 项目愿景

> 下一代 AI 浏览器自动化 Agent

---

## 🎯 核心产品哲学

传统 RPA 工具（如 Automa）是**命令式（Imperative）**的，强依赖人工绘制的"过程连线"。

本项目旨在构建**声明式（Declarative）**自动化系统：

### 核心理念

| 理念 | 说明 |
|------|------|
| **去画布化** | 放弃复杂的节点连线图。用户不定义"路径"，只定义"能力（Skills）"和"目标（规则）" |
| **大脑与肢体解耦** | AI（大脑）负责非确定性决策，引擎（肢体）负责确定性执行 |
| **声明式执行** | 用户定义"做什么"（Rule Book），AI 决定"怎么做"（动态选择 Skills） |
| **稳定性优先** | 基于"语义锚点"和"容器作用域"定位元素，不依赖坐标 |

### 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│ 表现层 (Presentation Layer)                                    │
│ ┌──────────────┐  ┌───────────────┐                         │
│ │ SidePanel    │  │ Dashboard      │                         │
│ │ - 录制器 UI  │  │ - 工具库管理   │                         │
│ │ - 检查模式   │  │ - Rule Book   │                         │
│ └──────────────┘  └───────────────┘                         │
├─────────────────────────────────────────────────────────────┤
│ 智能层 (Intelligence Layer)                                   │
│ ┌──────────────┐  ┌───────────────┐  ┌──────────────┐      │
│ │ Tool Builder │  │ Orchestrator   │  │ Self-Healing │      │
│ │ Agent        │  │ Agent         │  │ Agent        │      │
│ │ (构建时)     │  │ (运行时)      │  │ (维护时)     │      │
│ └──────────────┘  └───────────────┘  └──────────────┘      │
├─────────────────────────────────────────────────────────────┤
│ 执行层 (Execution Layer)                                     │
```

## 🧩 核心概念

### Scope + Anchor + Target

```
┌─────────────────────────────────────────────────────────────┐
│ 1. SCOPE - 找到所有容器                                      │
│    "tr" → [Row1, Row2, Row3, ...]                           │
├─────────────────────────────────────────────────────────────┤
│ 2. ANCHOR - 在容器中定位                                     │
│    ".name" contains "李四" → Row2                           │
├─────────────────────────────────────────────────────────────┤
│ 3. TARGET - 在定位的容器中操作                               │
│    ".btn-approve" → CLICK                                   │
└─────────────────────────────────────────────────────────────┘
```

### 五大基元

| 基元 | 说明 |
|------|------|
| `CLICK` | 点击元素 |
| `INPUT` | 输入文本 |
| `EXTRACT_TEXT` | 提取文本 |
| `WAIT_FOR` | 等待元素 |
| `NAVIGATE` | 页面导航 |

---

## 🔄 执行模式

### 纯 AI 迭代（推荐）

```
迭代循环（直到目标达成）：
├─ [观察] 获取页面状态（DOM → JSON）
├─ [思考] AI 决策（理解 Rule Book + 分析状态）
├─ [执行] 调用 Skill（Scope → Anchor → Target）
└─ [检查] 是否达成目标 → 否 → 继续
```
