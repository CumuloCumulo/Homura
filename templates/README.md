# 开发模板

本目录包含 Homura 项目的代码模板，用于快速创建新文件。

## 模板文件

### `function.template.ts`
函数模板，用于创建新函数。

**使用场景**：
- 添加新的 SDK 函数
- 添加工具函数
- 添加辅助函数

### `test.template.ts`
测试模板，用于创建新测试文件。

**使用场景**：
- 为新函数编写单元测试
- 为组件编写测试
- 编写集成测试

### `component.template.tsx`
React 组件模板，用于创建新组件。

**使用场景**：
- 创建 UI 组件
- 创建容器组件
- 创建布局组件

## 使用方法

1. 复制对应的模板文件
2. 重命名为目标文件名
3. 替换占位符：
   - `[功能名称]` → 实际功能名称
   - `[模块名]` → 实际模块名称
   - `[函数名]` → 实际函数名称
   - `[组件名]` → 实际组件名称
   - `[类型]` → 实际类型名称
4. 填充实现代码

## 占位符列表

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `[功能名称]` | 功能的中文名称 | 元素分析器 |
| `[函数名]` | 函数的英文名 | analyzeElement |
| `[组件名]` | 组件的英文名 | Button |
| `[模块名]` | 模块名称 | selector |
| `[类型]` | TypeScript 类型 | string, number |
| `[参数说明]` | 参数用途说明 | 目标元素 |

## 注意事项

1. **JSDoc 注释**：所有导出的函数/组件都必须有 JSDoc 注释
2. **错误处理**：使用 try-catch 并抛出有意义的错误信息
3. **类型安全**：明确指定参数和返回值类型
4. **测试覆盖**：为核心逻辑编写测试用例
